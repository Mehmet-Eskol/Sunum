Gömülü Sistem Nedir?

Belirli bir görevi yerine getirmek için, daha büyük bir cihazın içine gömülmüş, donanım ve yazılımdan oluşan özel amaçlı bilgisayar sistemidir.

🌡️Algıla
MCUKarar ver
⚙️Harekete geç

Her gömülü sistemin temel döngüsü: sensörden oku → işle → çıkışı sür

  • Özel amaçlı — tek bir işe odaklanır
  • Kısıtlı kaynak — KB düzeyinde RAM / Flash
  • Gerçek zamanlı — zamanında cevap kritik
  • Düşük güç — pille yıllarca çalışabilir
  • Güvenilir — yıllarca kesintisiz çalışma
  • Donanıma yakın — doğrudan register erişimi

"Hello World": LED Yakıp Söndürme

// STM32 — PA5 pinindeki LED'i yak/söndür
#include "stm32f4xx.h"

int main(void) {
  // 1) GPIOA saatini aç
  RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;

  // 2) PA5'i çıkış yap (MODER5 = 01)
  GPIOA->MODER &= ~(3U << (5 * 2));
  GPIOA->MODER |=  (1U << (5 * 2));

  while (1) {           // süper döngü
    GPIOA->ODR ^= (1U << 5); // toggle
    delay_ms(500);
  }
}

Register ve Bit İşlemleri

8-bit bir register'ın bitlerine tıklayın, değeri anında görün

Hex: 0x00
Dec: 0
Bin: 0b00000000
REG |= (1 << n);Biti 1 yap (set)
REG &= ~(1 << n);Biti 0 yap (clear)
REG ^= (1 << n);Biti tersle (toggle)
if (REG & (1 << n))Biti oku (test)
🌍 Gerçek hayatta Bir çamaşır makinesinde tek bir 8-bit durum register'ı "kapak kapalı", "su dolu", "motor dönüyor" gibi 8 farklı bilgiyi aynı anda tutabilir.

Kesmeler (Interrupts)

Polling (Yoklama)

CPU sürekli "buton basıldı mı?" diye sorar. Zaman ve enerji israfı.

Interrupt (Kesme)

Olay gerçekleşince donanım CPU'yu uyarır, ISR çalışır, ana işe dönülür.

Zamanlayıcılar ve PWM

PWM (Darbe Genişlik Modülasyonu), sabit frekanslı bir kare dalganın doluluk oranını (duty cycle) değiştirerek ortalama gücü kontrol eder.

  • LED parlaklığı
  • DC motor hız kontrolü
  • Servo motor açısı
  • Buzzer ile ses üretimi
fPWM = fCLK / ((PSC+1) · (ARR+1))
Ortalama voltaj: 1.65 V
🌍 Gerçek hayatta Drone'larda motor hızları, telefonlarda ekran parlaklığı, bilgisayarlarda fan hızı PWM ile ayarlanır. Model servolar 50 Hz'lik sinyalde 1–2 ms'lik darbe genişliğine göre açı alır.

Haberleşme Protokolleri

RTOS: Gerçek Zamanlı İşletim Sistemi

Süper döngü karmaşıklaştığında, işleri görevlere (task) bölen ve öncelik tabanlı zamanlayan bir çekirdek kullanılır.

  • Task — bağımsız iş parçacığı
  • Scheduler — önceliğe göre CPU paylaşımı
  • Queue — görevler arası veri aktarımı
  • Semaphore / Mutex — senkronizasyon
FreeRTOSZephyrThreadXRT-Thread
void vSensorTask(void *p) {
  for (;;) {
    int16_t t = read_temp();
    xQueueSend(q, &t, 0);
    vTaskDelay(pdMS_TO_TICKS(100));
  }
}

int main(void) {
  q = xQueueCreate(10, sizeof(int16_t));
  xTaskCreate(vSensorTask, "sens", 256,
              NULL, 2, NULL);
  vTaskStartScheduler();
}
🌍 Gerçek hayatta Bir akıllı saatte nabız sensörünü okuma (yüksek öncelik), Bluetooth iletişimi (orta) ve ekran çizimi (düşük) ayrı görevlerdir; RTOS bunları tek çekirdekte eşzamanlıymış gibi çalıştırır.

volatile neden önemli?

Derleyiciye "bu değişken senin bilgin dışında değişebilir, her seferinde bellekten oku" der.

  • Donanım register'ları
  • ISR ile paylaşılan değişkenler
  • RTOS görevleri arasında paylaşılan veriler

⚠️ Gömülü sistemlerde dinamik bellek (malloc) parçalanmaya yol açar; statik tahsis tercih edilir.

Tarihten Dersler

Gömülü yazılım hatalarının gerçek hayattaki bedeli

1996

Ariane 5 (Uçuş 501)

Ariane 4'ten aynen alınan kod, 64-bit ondalık hız değerini 16-bit tam sayıya çevirirken taştı. Roket kalkıştan yaklaşık 37 saniye sonra imha edildi.

int16_t v = 32765
Ders: Veri tiplerini ve değer aralıklarını asla varsayma.
1997

Mars Pathfinder

Düşük öncelikli bir görev mutex'i tutarken yüksek öncelikli görev bekledi (öncelik terslenmesi). Watchdog sistemi defalarca resetledi; Dünya'dan gönderilen yamayla öncelik kalıtımı açılarak düzeltildi.

Ders: RTOS senkronizasyonunu dikkatle tasarla; watchdog sistemi kurtarabilir.
1985–87

Therac-25

Radyoterapi cihazındaki yarış durumu (race condition) hatası, hastaların aşırı doz radyasyon almasına yol açtı. Önceki modellerdeki donanım güvenlik kilitleri kaldırılıp yazılıma güvenilmişti.

Ders: Güvenlik-kritik sistemlerde bağımsız donanım korumaları şart.
2013

Toyota davası

Ani hızlanma davasındaki bilirkişi incelemesi, motor kontrol yazılımında stack taşması riski, binlerce global değişken ve yetersiz watchdog tasarımı tespit etti.

Ders: MISRA C, statik analiz ve bellek bütçesi kullan.
